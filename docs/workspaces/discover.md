# Discover Workspace

**Goal**: see the best opportunities *now* without getting overwhelmed.

## Hero: Opportunity Radar

The hero element is the **Opportunity Radar** — a large canvas that maps candidates by:

- **Score / confidence** (signal strength proxy)
- **Liquidity** (volume proxy)
- **Volatility** (bubble size / intensity)

### How to use the radar

- Start broad: scan the “upper-right” (high score + high liquidity).
- Narrow using filters **without leaving the canvas**.
- Use the radar to pick a small set of candidates to inspect.

## Filters (compact rail)

Filters are intentionally vertical and compact so the radar remains the focal point:

- **Min confidence**: raise to reduce noise.
- **Min liquidity**: raise to avoid illiquid candidates.
- **Max risk**: lower to avoid high-risk candidates (when available in the feed).
- **Strategy**: limit to specific strategy sources.

## Signal Stream (supporting)

The signal stream is a **collapsible list of cards**:

- Sorted by **confidence × recency**
- Each card can expand to show details

### What to do next

When a signal looks compelling, move to **Decide** to focus on one candidate and review risk–reward and rationale.
