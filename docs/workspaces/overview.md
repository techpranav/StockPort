# Workspaces Overview (Trading OS)

Stockport’s UI is organized as a **Trading OS**: each workspace answers one question, with a clear “hero” visualization first.

## The five workspaces

- **Insight**: *What is the market + system state right now?*
- **Discover**: *What opportunities exist right now?*
- **Decide**: *Why is the algo recommending this trade?*
- **Execute**: *How are orders flowing and how clean is execution?*
- **Review**: *What happened and what did we learn?*

## Mental model

- **Discover → Decide**: You spot a candidate, then focus into a single signal to understand the rationale.
- **Decide → Execute**: You watch execution and operational health while orders move.
- **Review**: You analyze outcomes; charts first, tables second.

## The “signal-first” rule

Stockport emphasizes:

- **Values over labels** (numbers stand out)
- **One hero element per workspace**
- **Supporting details collapsed or secondary**
