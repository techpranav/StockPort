# Signal Cards

Signal cards are the primary unit in the **Signal Stream**.

## What a card shows (collapsed)

- **Symbol**
- **Signal label** (e.g., STRONG BUY / BUY / WATCH / AVOID)
- **Score**
- **Last price**
- **Timestamp**

## Details (expanded)

When expanded, a card can include:

- **Indicators** (if the feed includes them)
- **Risk metrics** (if the feed includes them)
- **Entry / stop / target** (if provided)

## How to use them

- Use the collapsed view for triage.
- Expand only when a candidate survives the radar + score filter.
- When you’ve selected a single candidate, switch to **Decide** to focus.
