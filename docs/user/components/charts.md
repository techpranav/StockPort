# Charts (Quick Reference)

Stockport uses a small set of core charts.

## Risk–Reward map (Decide)

Shows risk vs reward and an “ideal” reference line.
Use it to evaluate whether a candidate meets your baseline R:R standards.

## Order timeline (Execute)

Shows orders over time by lifecycle stage.
Use it to spot operational bottlenecks and confirm clean fills.

## Regime timeline (Insight)

Shows regime confidence over time when available.
Use it as supporting context for the current market environment.
