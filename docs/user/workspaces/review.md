# Review Workspace

**Goal**: understand performance and system learning over time.

## Hero: Performance chart (review-first)

Review is designed “charts first, tables second”.

Depending on available data, the hero should be a performance visualization (equity/P&L over time) or a replay timeline.

## Tabs

Review includes multiple tabs:

- **Performance**: key outcomes (P&L, win rate) and performance context.
- **Strategy Health**: per-strategy performance summaries.
- **Risk & Drawdowns**: exposure and risk summaries.
- **Learning & Decay**: learning/decay concepts and monitoring.
- **Replay**: step-by-step narrative from market state → signal → decision → execution.

## Using Review effectively

- Use it at end-of-day to validate whether the system behaved as expected.
- If drawdowns expand, check Strategy Health + Risk.
- Use Replay for “why did this happen?” investigation.
