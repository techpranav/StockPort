# Decide Workspace

**Goal**: focus on **one signal at a time** and decide whether it’s worth taking.

## Hero: Risk–Reward visualization

The hero element in Decide is the **Risk–Reward** chart.

- **What it shows**: each candidate’s risk vs reward estimate and an “ideal zone” reference line.
- **How to use it**:
  - Prefer higher reward for a given risk (better R:R).
  - Use it to compare a candidate to your baseline standards.

## Supporting sections (secondary)

### Signal details

The signal card includes:

- **Symbol**
- **Score / confidence**
- **Strategy source**
- **Price**

Expand the card to view additional details when provided by the feed.

### Indicator contribution (when available)

If indicators are present, they show the underlying factors.

### Portfolio impact (basic view)

This view summarizes estimated totals.

## Workflow

- Start in **Discover**
- Pick one candidate
- Use Decide to check **risk–reward first**, then inspect supporting details
