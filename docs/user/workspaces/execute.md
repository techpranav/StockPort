# Execute Workspace

**Goal**: stay calm and operational while orders flow.

## Hero: Order Timeline

The hero element is the **Order Timeline**, showing order lifecycle stages over time.

- **Why it matters**: execution quality is a function of reliability and latency.
- **How to use it**:
  - Look for clustering in “pending/submitted” states (potential bottlenecks).
  - Validate that filled orders progress cleanly through states.

## Supporting (secondary)

### Execution quality

Includes:

- **Quality score**: an aggregate score derived from fill rate, slippage, and latency.
- **Avg slippage**
- **Fill rate**
- **Avg latency**

### Active orders

Shows currently active/pending orders in a compact list.
