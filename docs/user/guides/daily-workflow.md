# Daily Workflow

This workflow matches Stockport’s Trading OS workspaces.

## 1) Insight (context first)

- Check **Algo Confidence** (hero)
- Confirm **Market Regime**
- Validate **System Health** (providers + latency)

## 2) Discover (find candidates)

- Scan the **Opportunity Radar**
- Apply compact filters (confidence, liquidity, strategy)
- Triaging with the Signal Stream cards

## 3) Decide (one at a time)

- Verify **Risk–Reward** first (hero)
- Inspect supporting rationale/indicators (when available)

## 4) Execute (operational calm)

- Monitor **Order Timeline** (hero)
- Watch **Execution Quality** (latency, slippage, fill rate)

## 5) Review (learn)

- Check performance outcomes
- Identify drawdowns/exposure changes
- Use replay to investigate “why” when available
