# Command Bar

The command bar is the always-visible top row of the UI.

## What it shows

- **Brand / context**: Stockport identity
- **Mode**: LIVE / PAPER / BACKTEST / REPLAY
- **Market**: a compact bullish/bearish/neutral label
- **Algo**: a compact confidence label

## How to use it

- Use **Mode** to confirm the operational context (especially before execution).
- Treat the Market + Algo summaries as *glanceable context*; deeper context lives in Insight.
