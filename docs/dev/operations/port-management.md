# Port management

If servers fail to start, it’s usually because ports are already in use.

## Default ports

- Backend API: `8001`
- Streamlit UI: `8501`
- Dev docs: `8000`
- User docs: `8002`

## Recommended: use the built-in scripts

- Start everything (backend + UI + docs): `start_all.ps1`
- Kill stuck processes: `kill_ports.ps1`
