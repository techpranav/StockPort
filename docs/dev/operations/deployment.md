# Deployment

This section documents deployment approaches for Stockport (local, VM, Streamlit Cloud, etc).

## Common deployment patterns

- **Local / personal machine**: simplest, fastest iteration.
- **Server/VM**: stable always-on backend, remote UI access.
- **Streamlit Cloud**: UI hosting (backend requirements may differ).
