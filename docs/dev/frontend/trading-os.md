# Trading OS Model (v5)

The UI is organized as **workspaces**, each with:

- **One hero visualization** (L1)
- Supporting tiles/sections (L2)
- Optional details (L3, typically collapsible)

## Why this model

Traditional dashboards are “container-first” and visually fatiguing.
The Trading OS model is **signal-first** so a user instantly knows where to look.

## Workspace mapping

- Insight → context + health
- Discover → opportunity radar + stream
- Decide → one candidate + risk–reward
- Execute → order timeline + quality
- Review → performance + replay
