# Prerequisites

## Required

- **Python**: 3.8+
- **Git**

## Recommended (for full system)

- **Redis**: used for event bus / pub-sub in backend workflows (depends on configuration)
- **Database**:
  - SQLite for development (default in many setups)
  - PostgreSQL for production-like environments

## Optional

- Broker/provider SDK credentials (for live data/execution), stored in environment variables.
