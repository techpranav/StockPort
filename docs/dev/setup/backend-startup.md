# Backend Startup

The UI expects a backend REST API reachable at `STOCKPORT_API_URL` (default `http://localhost:8001`).

## Start backend

Exact startup entrypoints can vary by branch. Common patterns in this repo:

- `python start_backend.py`
- `python -m backend.api.rest_api`

See also: [Server startup](../SERVER_STARTUP.md) and [Stockport v4 setup](../STOCKPORT_V4_SETUP.md).
