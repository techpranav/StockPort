# Settings

## What settings control

Settings determine how Stockport behaves, for example:

- Which providers are enabled
- Which symbol universe is scanned
- Strategy enable/disable and parameter tuning
- Risk limits and capital allocation
- Execution mode (manual / paper / live)

## Safe defaults

For new users:

- Start with **manual execution**
- Use a **small universe**
- Enable **1–2 strategies** and learn their behavior
