# Alerts

## What alerts do

Alerts notify you when something important happens, for example:

- A high-confidence signal appears
- Provider health changes (GREEN → YELLOW/RED)
- A risk limit is hit
- Execution events (submitted/filled/rejected)

## How to use alerts effectively

- Keep alerts **high signal**: enable only the ones you act on.
- Tie alerts to your workflow: Discover → Decide → Execute.
